# Brief — The Library Catalog

What the library requires of its catalog. Library staff keep the catalog of the books the library
holds and the copies it owns.

## Books, works and copies

- A book is registered together with its first physical copy. One record results. A registration
  that offers no copy is refused.
- A book is one edition of a work. Registering an edition of a work the library does not yet hold
  creates the work as well. The edition records which work it belongs to.
- A further edition of a work the library already holds can be registered. It joins that work. It
  does not create another work. A further edition holds no copies until one is registered, and it
  can still be retrieved.
- A further copy can be registered against a registered book. A copy belongs to exactly one
  edition.
- A copy can be registered against a retired book.
- Every copy is registered as registered, whatever state the request gives it.

## What a registration must contain

- A registration with no subject is refused.
- A book, a work or a further edition that is missing what the library says it must contain is
  refused. Nothing is registered by it, whatever description the request states.
- What the catalog checks for a registration is what it records.

## Sameness

- A registration with the same title, author and publication year as a registered book is refused.
  Differences in case and spacing do not make a second record.
- A copy with a barcode the library already owns is refused.
- A registration repeating an edition's identity is refused.

## Changing and retiring

- Bibliographic information can be updated, and a later retrieval returns the new version.
- An update that would duplicate another registered book is refused.
- A correction keeps the record's state.
- A correction that leaves a book without its description is refused.
- A copy can be retired, and its book is unaffected. A retired copy can be returned to the
  registered state.
- A book can be retired, and its copies are unaffected. A retired book can be returned to the
  registered state.
- Retiring one edition leaves the work's other editions alone. A work is never retired, whatever
  happens to its editions.

## Finding

- A search by subject finds the registered books with that subject. A search by title finds a
  registered book by name.
- A search returns bibliographic information and nothing about copies.
- A search answers once per work, not once per edition. The one result carries the work's editions
  to choose between.
- A retired book does not appear in search results, and its details can still be retrieved.
  Reinstating it puts it back in search.
- A book's complete details include the copies held and the work it belongs to.

## Authority and record

- A staff member the library has not authorized performs nothing. Nothing changes, whatever rules
  the request states.
- A request that states rules of its own is judged by the catalog's rules. It is not refused for
  stating them.
- Every operation performed can be traced afterwards.
